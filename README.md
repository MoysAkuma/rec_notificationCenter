# rec_notificationCenter
API de recepción en Spring Boot para manejar la API NotificationCenter.

## Stack
- Spring Boot 3.x
- Apache Camel (Spring Boot Starter)

## Endpoints Camel (capa de recepción)
- `POST /api/notifications`

## Swagger / OpenAPI
- Contrato escrito: `/swagger/notification-center.yaml`
- Documento OpenAPI generado por Camel Rest DSL: `/api/api-doc`

## Ejecución
```bash
mvn spring-boot:run
```
